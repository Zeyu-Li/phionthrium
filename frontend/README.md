# Phionthrium frontend

A React app built with [Vite](https://vite.dev/). Use Node 24 and yarn.

## Available Scripts

In the `frontend` directory, you can run:

- `yarn start`: runs the app in development mode with hot reload.
- `yarn test`: runs the tests once with [Vitest](https://vitest.dev/).
- `yarn build`: builds the app for production into the `build` folder.
- `yarn preview`: serves the production build locally.
